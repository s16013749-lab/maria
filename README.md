# AURELLE — Weddings & Events

## О проекте

AURELLE — адаптивный сайт свадебного организатора.

На сайте представлены этапы подготовки свадьбы, услуги,
обратный отсчёт до события и форма заявки на консультацию.

Оформление выполнено в нежно-розовых и нежно-зелёных оттенках.

## Ссылка на сайт

Добавьте сюда реальную ссылку на сайт после публикации на Netlify.

## Технологии

- HTML5 — структура страницы.
- CSS3 — оформление, адаптивность и анимации.
- JavaScript — интерактивные функции.
- localStorage — сохранение настроек.
- Netlify Forms — приём заявок после настройки и публикации.

Сторонние библиотеки не используются.

## Возможности

- Навигация по разделам с плавной прокруткой.
- Кнопка «Наверх».
- Анимация появления карточек при прокрутке.
- Поиск услуг по названию и описанию.
- Фильтрация услуг по категориям.
- Совместная работа поиска и фильтра.
- Модальное окно с подробностями услуги.
- Слайдер с переключением стрелками.
- Обратный отсчёт до выбранной даты свадьбы.
- Переключение русского и английского языка.
- Сохранение настроек после перезагрузки страницы.
- Проверка формы заявки.
- Страница ошибки 404.

## Структура проекта

- index.html — главная страница.
- style.css — оформление и адаптивность.
- script.js — логика сайта.
- 404.html — страница для несуществующего адреса.
- README.md — описание проекта и инструкция.

## Локальный запуск

1. Скачать проект и распаковать архив.
2. Открыть папку проекта в Visual Studio Code.
3. Открыть index.html в браузере.

Также можно запустить сайт через расширение Live Server.

Установка зависимостей и сборка не требуются.

## Использование таймера

1. Перейти в раздел «До свадьбы».
2. Выбрать дату и время в будущем.
3. Нажать «Начать отсчёт».

Выбранная дата сохраняется в браузере.
При повторном открытии страницы отсчёт восстанавливается.

Чтобы удалить сохранённую дату, нужно нажать «Сбросить».

Используется часовой пояс устройства пользователя.

## Поиск и фильтрация

В разделе «Услуги» можно:

- выбрать категорию;
- ввести название или описание в строку поиска;
- использовать поиск и категорию одновременно.

Поиск выполняется по тексту услуг на выбранном языке.

## Переключение языка

Кнопка в правом верхнем углу переключает основной интерфейс
между русским и английским языком.

Выбранный язык сохраняется после обновления страницы.

## Сохранение данных

В localStorage сохраняются:

- язык интерфейса;
- дата события;
- категория услуг;
- поисковая строка.

Имя, телефон и пожелания из формы в localStorage не сохраняются.

## Форма заявки

Форма проверяет:

- имя;
- номер телефона;
- дату свадьбы.

Отправка выполняется через Netlify Forms.

Для приёма заявок необходимо включить обнаружение форм
в Netlify и повторно опубликовать сайт.

После публикации нужно проверить наличие формы
wedding-contact в разделе Forms и отправить тестовую заявку.

При локальном запуске отправка отключена.

## Публикация

1. Загрузить файлы в публичный репозиторий GitHub.
2. Подключить репозиторий к Netlify.
3. Настроить публикацию из ветки main.
4. Указать папку с index.html как папку публикации.
5. Проверить успешное завершение деплоя.
6. Добавить адрес опубликованного сайта в раздел
   «Ссылка на сайт» этого README.

## Проверка страницы 404

После публикации открыть несуществующий путь на сайте,
например /test-error.

Должна появиться страница 404 с кнопкой возврата на главную.

## Настройка контактов и цен

Перед использованием сайта необходимо указать собственные
телефон, почту, адрес и актуальные цены.

Текст адреса задаётся в index.html и в переводах script.js.
Цены услуг находятся в массиве services в script.js.
